# Alba Estética · Landing page

Landing page para uma clínica de estética avançada. A marca é fictícia e foi criada para portfólio.

🔗 **Site no ar:** [adicione o link da Vercel]

## Destaques
- Abertura com foto em tela cheia, título animado linha por linha e cartão de agendamento
- Quiz "Descubra o tratamento ideal": três perguntas que geram uma indicação e abrem o WhatsApp com as respostas já preenchidas
- Tratamentos organizados por categoria (Facial, Corporal, Laser), com abas acessíveis por teclado
- Perguntas frequentes com `<details>`, galeria horizontal e layout responsivo
- Respeita `prefers-reduced-motion`

## Tecnologias
HTML, CSS e JavaScript puro, sem frameworks.
